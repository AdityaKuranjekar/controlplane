How Chain Verification Works
Each row stores SHA256(canonicalJSON(row) + prev_hash). The verifier recomputes every hash client-side using the Web Crypto API and checks that each record's prev_hash equals the preceding row's row_hash. Any tampering breaks the chain immediately.

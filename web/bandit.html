How the Bandit Works
Each candidate threshold τ is an arm. On every cache lookup, the bandit draws a sample from each arm's Beta(α,β) posterior and selects the arm with the highest sample. Successes (correct cache hits) increment α; failures increment β. Over 300 rounds, the bandit converges on τ = 0.85 — the arm that maximises reward without false hits.

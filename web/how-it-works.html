A BLOCK at any stage short-circuits the pipeline — the response is returned immediately without calling the LLM. This ensures attacker prompts never reach the model.

L0
Pre-Gate: PII Redaction & Injection Guard
Runs before any LLM call. Average execution time: <1ms.
Block-Before-Send

PII Scanner — Uses a regex pipeline with Luhn algorithm validation for credit cards. Detected entities: CC, SSN, EMAIL, PHONE, IP, DOB. PII tokens are replaced with [PII:TYPE] placeholders before the prompt is processed further.

Injection Guard — 14+ regex patterns covering: direct system override attempts (SYSTEM_OVERRIDE), DAN jailbreaks, role-play bypasses, Base64 obfuscation, token injection patterns, and prompt continuation attacks. A BLOCK verdict returns immediately with a 403-equivalent response — no LLM called.

🔒 Luhn-validated card scan 🛑 14+ jailbreak patterns ✂️ PII tokenization ⚡ <1ms execution
L1
Inference: Semantic Cache + Frugal Model Cascade
Cache-first architecture. LLM only called on cache MISS.
Cache-First

Semantic Cache — A compound hash of SHA256(prompt + context + profile) is used to look up previous responses in a FAISS vector index. If the cosine similarity to a cached embedding exceeds τ (default 0.85, tuned by the bandit), the cached response is returned in ~11ms instead of calling the LLM.

Frugal Cascade — On cache MISS, a multi-tiered router tries models in cost order: Llama 3.1 8B → Llama 3.3 70B → Mixtral 8x7B. Each model returns a confidence score. If the Tier-0 model passes the confidence threshold, escalation to a more expensive model is avoided. This achieves 92.7% cost reduction vs. always calling the largest model.

📊 FAISS vector index 🎰 Thompson bandit τ tuning 💰 92.7% cost reduction ⚡ 11.4ms cache hit latency
L2
Verification: NLI Grounding Gate
Active only for internal_rag profile. Stops hallucinations before delivery.
RAG Profile Only

Natural Language Inference — After the LLM generates a response, an NLI model scores the entailment relationship between the response and the provided RAG context chunks. If the entailment score falls below the calibrated threshold τ, the response is flagged or blocked.

Conformal Calibration — The threshold τ is not manually set. It is derived via conformal prediction: given a target false-negative rate α (max 20% by default), the calibration algorithm finds the lowest τ that guarantees P(false negative) ≤ α on a held-out calibration set. This gives a statistical guarantee, not just a heuristic.

📐 NLI entailment scoring 📊 Conformal prediction 💯 100% hallucination recall at α=20%
L3
Governance: Tool Intent Contracts
Active only for decision_agent profile. Enforces action scope.
Agent Profile Only

Intent Contracts — Each tool call made by an agent is checked against a signed policy contract specifying allowed actions, parameter constraints, and dual-approval requirements. An agent attempting to execute a wire transfer without dual approval, or calling a tool outside its whitelist, is immediately blocked.

Design Goal — Prevent AI agents in regulated workflows (financial services, healthcare) from taking irreversible real-world actions that weren't explicitly authorized by the policy contract. Zero-tolerance profile: any contract violation results in BLOCK.

📝 Signed policy contracts 🔐 Dual-approval enforcement 🛑 Zero-tolerance BLOCK
L4
Audit: SHA-256 Hash-Chained Ledger
Runs after every request, regardless of outcome. WORM-compliant.
Always Active

Cryptographic Chaining — Every inference decision is written to SQLite with row_hash = SHA256(canonicalJSON(row) + prev_hash). Each record includes the profile, redacted prompt, action taken (ALLOW/BLOCK/REDACT), reason, risk vector, and latency breakdown.

Tamper Evidence — Because each hash includes the previous row's hash, modifying any historical record breaks the chain from that point forward. The Audit Explorer page re-runs the hash verification client-side using the Web Crypto API, with no server trust required.

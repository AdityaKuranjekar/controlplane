🔬 How the Pipeline Works
L0
Pre-Gate: PII & Injection Scan
Every prompt passes through a Luhn-validated PII scanner (cards, SSNs, emails) and an expanded regex injection filter covering DAN jailbreaks and system-tag overrides. Runs in <1ms. Blocks or redacts before the model is ever called.
L1
Inference: Semantic Cache + Frugal Cascade
A compound hash (prompt + context + profile) checks FAISS for a cached embedding match. On MISS, a multi-armed bandit routes to the cheapest model tier (Llama 3 8B → 70B → Mixtral) that can answer confidently.
L2
Verification: NLI Grounding Gate
For RAG use cases, a Natural Language Inference model scores whether the response is entailed by the provided context. Responses below the entailment threshold are flagged or blocked — stopping hallucinations before delivery.
L3
Governance: Tool Intent Contracts
For agentic/decision use cases, each tool call is checked against a signed contract: allowed action types, dual-approval requirements, and scope limits. Out-of-scope actions are rejected before execution.
L4
Audit: SHA-256 Hash-Chained Ledger
Every inference decision — allow, block, or redact — is written to a WORM-compliant SQLite ledger with a SHA-256 hash linking each record to the previous. Tamper-proof, verifiable in the Audit Explorer.
